# DLLs do AutoCAD 2022

Copie as seguintes DLLs da máquina com AutoCAD 2022 para esta pasta:

- `acmgd.dll`
- `accoremgd.dll`
- `acdbmgd.dll`

Origem típica: `C:\Program Files\Autodesk\AutoCAD 2022\`

Estas DLLs são necessárias para compilar a versão do plugin compatível com AutoCAD 2022 (.NET Framework 4.8).
